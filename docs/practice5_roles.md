# Права на сайте Ghost

Фанат смотрит каталог и ведёт свои билеты. Гуль только смотрит каталог.
Менеджер тура ведёт афишу. Администратор меняет дискографию, состав, мерч,
пользователей и может стереть запись навсегда.

| Операция | Фанат | Гуль | Менеджер | Администратор |
|---|---|---|---|---|
| Просмотр альбомов, треков, мерча, состава и афиши | Да | Да | Да | Да |
| Взять билет на концерт в статусе «план» | Да | Нет | Нет | Нет |
| Вернуть свой билет | Да | Нет | Нет | Нет |
| Создание и изменение концертов | Нет | Нет | Да | Да |
| Логическое удаление концертов | Нет | Нет | Да | Да |
| Изменение альбомов, треков, мерча и состава | Нет | Нет | Нет | Да |
| Физическое удаление и восстановление | Нет | Нет | Нет | Да |
| Пользователи, роли и статистика | Нет | Нет | Нет | Да |

Подмена роли в localStorage меняет только кнопки. Сервер читает роль из
подписанного токена и отвечает 403.

Учебные учётки: `fan / fan123`, `ghoul / ghoul123`, `manager / manager123`,
`admin / admin123`.
